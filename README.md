# When Tomorrow Felt Brighter

An interactive journey into shared memories of ordinary evenings and everyday
optimism in 2010s China.

The current prototype uses original pixel art throughout. The opening flower
valley leads directly to a draggable, zoomable pixel town with eight connected
places, each representing shared aspirations, sounds, and everyday life in the
2010s. There is no transition scene between the valley and town.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
