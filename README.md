# The Internet Forgot the Afternoon

An interactive memory archive about ordinary childhood attention in 2010s China.

The current prototype opens in an original WebGL night valley. Thousands of
glowing flower particles respond to the cursor while wheel and touch input move
the camera through the landscape. The interface includes responsive navigation,
an ambient sound toggle, a loader, and a dispersal transition on the central CTA.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
