# When Tomorrow Felt Brighter

An interactive journey into shared memories of ordinary evenings and everyday
optimism in 2010s China.

The current prototype opens in an original WebGL night valley. Thousands of
glowing flower particles respond to the cursor while wheel and touch input move
the camera through the landscape. The central CTA becomes a star-flight transition
into a draggable, zoomable miniature night town, where eight connected places
represent shared aspirations, sounds, and everyday abundance from the 2010s.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
